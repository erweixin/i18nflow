# 🎯 i18nflow 推广核心要点

## 一句话描述

> **让翻译人员直接在页面上编辑，消除开发和翻译之间的沟通成本**

## 三大核心卖点

### 1. 👥 团队协作革命 ⭐ 最重要

**传统痛点：**

```
开发导出 → 翻译 Excel → 创建文档 → 来回沟通 →
开发录入 → 测试验证 → 发现问题 → 重复...
```

⏰ 一个文案调整：30分钟 - 2小时

**i18nflow 方案：**

```
翻译人员：Ctrl+点击页面 → 编辑 → 预览 → 保存 → 完成
```

⚡ 同样的工作：10秒

**价值：**

- 翻译人员独立工作，不需要懂代码
- 所见即所得，立即看到实际效果
- 零沟通成本，节省 90% 时间

### 2. 🤖 AI 自动翻译

**传统痛点：**

- 手动翻译耗时
- 复制粘贴到翻译工具
- 翻译质量不稳定

**i18nflow 方案：**

- 输入中文 → 点击按钮 → 3个候选翻译
- 2秒完成，快 30 倍
- AI 理解上下文，翻译更准确

### 3. 🚀 所见即所得 + 热更新

**传统痛点：**

- 找文件、找 key
- 保存、刷新页面
- 看不到实际效果

**i18nflow 方案：**

- Ctrl+点击文字直接编辑
- 保存即生效，无需刷新
- 实时预览效果

## FAQ 预设

### Q1: 翻译人员需要懂代码吗？

**A:** 完全不需要！只需要：

1. 打开浏览器访问开发环境
2. Ctrl+点击页面文字
3. 编辑翻译
4. 保存

就像使用 Google Docs 一样简单。

### Q2: 和 Crowdin/Lokalise 这些翻译平台有什么区别？

**A:**

- Crowdin/Lokalise：离线翻译平台，需要导出/导入
- i18nflow：直接在实际页面上编辑，所见即所得
- 适用场景不同，可以互补使用

### Q3: 生产环境会包含调试代码吗？

**A:** 不会！通过构建工具配置（如 `isDev &&`），只在开发环境加载。

### Q4: 支持哪些技术栈？

**A:**

- 已支持：React + Rspack/Vite + Kiwi-Intl
- 计划中：react-intl, react-i18next, vue-i18n, Vue...

### Q5: AI 翻译需要付费吗？

**A:** 需要 OpenRouter API Key（付费），但费用很低（平均每千次 < $1）。也可以不使用 AI，手动翻译。
