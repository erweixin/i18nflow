# 🚀 i18nflow - 让国际化开发变得简单

## 😫 团队的痛点

### 传统的国际化开发流程

**单人开发模式：**

```
1. 写代码 → 2. 找语言文件 → 3. 添加翻译 → 4. 刷新页面 → 5. 重复...
```

**团队协作模式（更痛苦）：**

```
产品/设计 → 开发实现 → 导出文案 → 翻译人员翻译 →
创建文档 → 来回沟通 → 开发录入 → 测试验证 → 发现问题 → 重复...
```

**核心问题：**

- 🔄 **开发痛点**：在代码和语言文件间反复切换，效率低
- 📝 **翻译痛点**：只能在 Excel/文档中翻译，看不到实际效果
- 🤝 **协作痛点**：需要导出文案、创建文档、来回沟通，流程冗余
- 🐛 **测试痛点**：翻译 key 不匹配、上下文不符，很难发现
- 😵 **调试困难**：改一个词要走完整流程，反馈周期长（数小时到数天）

**时间成本：**

- 开发添加一个翻译：~3 分钟
- 翻译人员调整一个文案：~30 分钟（包含沟通）
- 发现问题到修复：~2 小时（跨团队协作）

## ✨ i18nflow 的解决方案

**所有人都能在页面上直接编辑翻译，实时生效！**

### 🎯 新的协作流程

```
产品/设计 → 开发实现 → ✅ 完成！

翻译人员：直接在页面上 Ctrl+点击 → 编辑 → 保存 → 立即看到效果
开发人员：Ctrl+点击 → 编辑 → AI 翻译 → 保存 → 完成
测试人员：发现问题 → Ctrl+点击 → 立即修改 → 验证
```

**核心改变：**

- ❌ 不再需要导出文案、创建文档
- ❌ 不再需要翻译和开发之间来回沟通
- ❌ 不再需要开发手动录入翻译
- ✅ **翻译人员直接操作页面，所见即所得**
- ✅ **开发人员只需关注功能实现**
- ✅ **测试人员可以直接修正问题**

只需 3 行配置，无需修改业务代码

```javascript

});
```

## 🎯 快速开始

### 1. 安装

```bash
pnpm add @i18nflow/kiwi kiwi-intl
```

### 2. 配置（3 行代码）

```javascript
// rspack.config.js
import { KiwiRspackPlugin } from '@i18nflow/kiwi';

export default {
  plugins: [
    new KiwiRspackPlugin({
      i18nIdentifier: 'I18N',
      localeDir: 'src/locales',
    }),
  ],
};
```

### 3. 使用

开发环境下：

- **Ctrl + 点击** 页面上的文字
- 编辑翻译

## 📚 适用场景

✅ **非常适合，如果你的团队：**

- 👥 **有专门的翻译人员**（让他们直接在页面上工作）
- 🌍 **需要多语言支持**（中英日韩等多语言团队协作）
- 🚀 **快速迭代产品**（频繁修改文案和添加功能）
- 🎨 **产品/设计经常调整文案**（他们可以自助修改）
- 🧪 **测试团队发现翻译问题**（立即修正，无需提 Bug）

✅ **也适合，如果你是：**

- 💻 **独立开发者**（AI 翻译帮你快速生成多语言）
- 🏃 **创业团队**（提高效率，减少沟通成本）
- 📱 **外包团队**（客户可以直接在页面上审阅和修改翻译）

❌ **可能不需要，如果：**

- 只有一种语言，无国际化需求
- 翻译在发布前一次性完成，不再修改
- 团队已有成熟的翻译管理平台（如 Crowdin、Lokalise）
