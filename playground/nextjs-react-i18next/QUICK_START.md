# 快速开始

## 一键启动

```bash
npm run dev
```

就这么简单！该命令会同时启动：

- **Next.js 应用** (端口 3033)
- **i18n 开发服务器** (端口 3034)

## 访问应用

打开浏览器访问：http://localhost:3033

## 编辑翻译

1. 按住 **Ctrl + Shift** (Windows/Linux) 或 **Cmd + Shift** (Mac)
2. 点击页面上任意翻译文案
3. 在弹出的编辑框中修改内容
4. 点击"保存"
5. 页面会自动刷新，显示新的翻译内容

## 工作原理

```
┌─────────────────────────────────────────────────────┐
│  浏览器 (http://localhost:3033)                      │
└────────────────┬────────────────────────────────────┘
                 │
                 │ 访问页面
                 ▼
┌─────────────────────────────────────────────────────┐
│  Next.js 应用 (端口 3033)                            │
│  - 渲染页面                                          │

│  - GET  /api/i18n/health                            │
└─────────────────────────────────────────────────────┘
```

## 常见问题

### Q: 为什么需要两个服务器？

A: Next.js 不支持 webpack-dev-server 的 middleware 配置，因此我们使用独立的服务器来提供 i18n API。

### Q: 如何修改端口？

A: 修改 `package.json` 中的 `dev:i18n` 脚本：

```json
"dev:i18n": "i18n-dev-server -p 自定义端口 ..."
```

同时更新 `next.config.js` 中的 rewrites 配置。

### Q: 生产环境会包含这些功能吗？

A: 不会。所有调试功能仅在开发环境启用，生产构建不包含任何调试代码。
